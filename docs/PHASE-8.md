# Phase 8 · AI workflows and privacy

Open **Rules assistant** in the synthetic HTTPS demo. Choose **2027 scenario**. At source lookup date **2026-11-20**, the source metadata shows the change as upcoming. Switch the lookup date to **2027-01-01** and the upcoming message disappears. The answer includes the authority, source version, available-from date, effective date where specified, and the supplied challenge page citation. The separate external link is public context. Dates not specified by the challenge are labelled unspecified. Source resolution gives priority to authority and then the newest available version; equal-ranked conflicting approved statements produce a review message. The conflict path is covered by a generated test fixture.

The three workflows are local cited rule retrieval, deterministic protected aggregate analysis, and intake category suggestions for human confirmation. In July's group-analysis fixture, choose the lowest and highest observed A1 cohort questions to see the released group and denominator. The monthly question uses the same two released totals as the management dashboard. It shows 37/96 and 39/96 for September and October, an increase of two recorded on-time results. The answer does not infer a cause. The aggregate responses are restricted to the demo and management roles and the synthetic profile. The local rule request path does not load case rows.

The privacy preview uses fictional input and shows only the fixed topic, locale and date in the release. The assistant has no free-text entry. Unapproved query fields or values are rejected without echoing or logging their contents. For example, this is a safe synthetic rejection demonstration:

```text
/ai?topic=invalid-demo
```

Tests cover source precedence and confusion, synthetic canary rejection, role restrictions, local PDF OCR and controlled release. No language model or external inference service was used. Use of an approved generative model and evaluation on a representative privacy test set are open institutional acceptance items.
