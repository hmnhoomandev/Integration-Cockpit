# Phase 6 · Trilingual cockpit and role journeys

Sign in to the synthetic HTTPS demo using the authorized judge account. In the sidebar, use **Demo role** and **View role** to see the caseworker, management and import operator journeys. **Demo account** returns to the ordinary judge view. Switching applies real backend access restrictions in that session and is available only to a judge account in the hosted synthetic profile.

- **Caseworker** is assigned to A in the fixture. Open **Casework**, search for DEMO-00001, and try an unmatched filter. The table shows the selected filters, the count and a clear empty state. A direct URL for DEMO-00003 is denied for this assignment.
- **Management** sees the source coverage, monthly comparison of September and October, and the group explorer. Case URLs are denied.
- **Import operator** lands on the reporting workspace and can replay a synthetic import or download the quality report. Individual results exports are denied.

The locale switch preserves the current case or supported view, selected filters, and page where applicable. The skip link gives keyboard users direct access to the main content. Tables can scroll within mobile layouts. The coverage tile reports detected workbooks separately from workbooks with data rows. The trend compares two synthetic months and includes the eligible denominator. A change in rate is descriptive, with each month evaluated at its own report date.

The phase leaves original workbook headings, IDs, source names and some technical codes in their source form. Browser checks cover three languages, three role views, keyboard navigation, access denials and mobile layout. This is a functional accessibility check and does not constitute an independent accessibility audit.
