**Short description**

Integration Cockpit Bern turns eleven monthly Excel exports into an evidence-based casework queue and a management dashboard. It shows which deadlines apply, which evidence supports a result, and which cases need a follow-up. Each month can be re-imported and downloaded as a reconciled Excel report in German, English or French.

**Impact**

A caseworker can find a due A1 case, understand the reason and see the status update once new evidence arrives. Managers can see observed group outcomes and caseload with denominators, compare an illustrative 2027 cutoff, and identify ZEMIS employment discrepancies.

**Use of AI and model validation**

The demo uses local cited retrieval for rules, a protected aggregate question workflow and human-approved local PDF suggestions. Aggregate forecasting compares simple baselines and a trend candidate on a generated time series. The interface shows holdout error, an interval, and data provenance. The tested configuration makes no external inference calls.

**Data**

The demo uses invented records. It includes two reproducible monthly datasets and clearly labels its public FSO comparison, synthetic forecast series and rule-derived results. The hosted profile requires sign-in and disables arbitrary uploads.
